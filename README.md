# بوفية توب كبدة — مشروع موحّد

يحتوي هذا المستودع على:
- `index.html`: موقع الكاشير المنشور عبر GitHub Pages.
- `local-print-bridge/`: خدمة الطباعة التي تعمل على كمبيوتر Windows المتصل بالطابعات.

## مهم: GitHub Pages لا يشغّل خدمة الطباعة

GitHub Pages يستضيف ملفات الموقع الثابتة فقط. وجود `bridge.py` في المستودع لا يشغّله تلقائيًا؛ يجب تشغيله محليًا على كمبيوتر الكاشير.

## النشر على GitHub

1. افتح مستودع `hobe-1/Abod1`.
2. ارفع واستبدل `index.html` الموجود في جذر المستودع بهذا الملف.
3. ارفع مجلد `local-print-bridge` كاملًا إلى جذر المستودع.
4. احفظ التغييرات وانتظر نشر GitHub Pages.
5. افتح `https://hobe-1.github.io/Abod1/` ثم نفّذ تحديثًا قويًا بـ `Ctrl+Shift+R`.

## تشغيل الطباعة على Windows

1. على كمبيوتر الكاشير، افتح مجلد `local-print-bridge` الذي رفعته إلى GitHub ونزّله، أو نزّل المستودع كاملًا عبر Code → Download ZIP.
2. فك الضغط في مجلد ثابت.
3. ثبّت Python 3 إن لم يكن موجودًا، مع تفعيل خيار Add Python to PATH أثناء التثبيت.
4. شغّل `local-print-bridge/install.bat` وانتظر اكتماله.
5. شغّل `local-print-bridge/run.bat` واترك نافذته مفتوحة.
6. على الكمبيوتر نفسه افتح `http://127.0.0.1:3210/health`، ثم `http://127.0.0.1:3210/printers`.
7. تأكد من ظهور `ok: true` وأسماء الطابعات. عرّف طابعة USB وطابعة Ethernet في Windows أولًا إن أمكن.

## التحقق قبل الاعتماد

- اطبع طلبًا تجريبيًا واحدًا أولًا.
- تحقق من اسم الصنف والكميات والأسعار والإجمالي.
- تحقق من وصول الطلب إلى Firestore ومن ظهوره على جهاز الكاشير.
- لم يتم اختبار الاتصال الفعلي بحساب Firebase أو بطابعات المستخدم من داخل هذه الحزمة؛ لذلك يلزم إجراء الاختبار أعلاه قبل الاستخدام التجاري.

## الأمان

خدمة الطباعة مربوطة على `127.0.0.1` فقط وتقبل الطلبات من نطاق GitHub Pages المحدد في الكود. لا تفتح المنفذ 3210 على الإنترنت أو على الراوتر.
