# بوفية توب كبدة

هذه نسخة الموقع المجهزة للنشر على GitHub Pages. تم تصحيح إعدادات Firebase داخل `index.html` لتشير إلى المشروع `gggg-8085a` بدلًا من مشروع مختلف كان موجودًا في النسخة السابقة. كما أصبح الموقع يعرض تنبيهًا إذا فشل حفظ الطلب في Firestore بدلًا من الإيحاء بأن الحفظ نجح.

## النشر
1. ارفع `index.html` إلى جذر مستودع GitHub باسم `index.html`.
2. افتح **Settings → Pages**.
3. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، ثم **Save**.
4. افتح رابط الموقع المنشور بعد اكتمال النشر.

## إعدادات Firebase المطلوبة
- تأكد أن **Authentication → Sign-in method → Anonymous** مفعّل في المشروع `gggg-8085a`.
- تأكد أن Firestore مفعّل وأن قواعد `orders` تسمح للمستخدم المصادق عليه بإنشاء وقراءة وتحديث الطلبات.
- يجب إعداد قواعد `appData` بشكل مناسب إذا كنت تريد مزامنة إعدادات الأصناف عبر الأجهزة. لا تفتح القراءة والكتابة للعامة.

## التحقق
إذا ظهر تنبيه فشل الحفظ، افتح وحدة تحكم المتصفح وسجّل الخطأ الظاهر في Firebase؛ غالبًا يكون رفض صلاحيات أو إعداد مصادقة. لا تعتبر الطلب محفوظًا في Firestore إلا إذا ظهر مستنده داخل مجموعة `orders`.

## الطباعة
الطباعة المحلية تحتاج تشغيل Print Bridge على كمبيوتر الكاشير؛ نشر الموقع وحده لا يثبت خدمة الطباعة.
